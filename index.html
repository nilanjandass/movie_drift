TMDb Connection

Use live movie and series data

Add a TMDb API key to fetch current releases, series, posters, credits, and metadata. The key is stored only in this browser.

How to get a TMDb API key

  1. Open TMDb API settings and sign in or create a free account.
  2. Request an API key from the API section and complete the short form.
  3. Paste the key above, then select Save key.
